# MELLOY 캐릭터 검수기 v0.1

캐릭터 설정을 **템플릿 양식으로 작성**하고, **원본 설정과 생성 결과를 비교해서 검수**하는 데스크톱 프로그램입니다.

**모바일 작성기(웹앱)**: https://m1nch0wh4ck.github.io/charameka/ — 휴대폰·아이패드 브라우저에서 열고 앱으로 설치할 수 있습니다.

## 실행 방법
1. [Python](https://www.python.org/downloads/)을 설치합니다. (설치 화면에서 **Add python.exe to PATH** 체크)
2. 이 폴더의 **`실행하기.bat`** 을 더블클릭합니다.
   - 처음 실행할 때 필요한 라이브러리(PySide6)를 자동으로 설치합니다.
3. (선택) AI 의미 검수를 쓰려면 Claude Code를 설치하고 로그인합니다.
   - PowerShell에서 `irm https://claude.ai/install.ps1 | iex` 실행 → 명령 프롬프트에서 `claude` 입력 후 로그인

## exe로 만들기 (선택)
파이썬 없이 더블클릭으로 바로 실행되는 exe 폴더를 만듭니다.
1. 위의 `실행하기.bat`을 한 번 실행해서 PySide6가 설치된 상태로 만듭니다.
2. **`exe만들기.bat`** 을 더블클릭합니다. (처음에는 3~5분 걸립니다)
3. 완료되면 폴더가 두 개 생깁니다.
   - `배포\MELLOY 캐릭터 검수기` — **내가 쓸 폴더**. 폴더째 원하는 곳으로 옮겨 쓰시면 됩니다.
     다시 만들 때 이 폴더의 `rules`, `예시`에서 고친 내용은 덮어쓰지 않습니다.
   - `배포\공유용\MELLOY 캐릭터 검수기` — **지인에게 보낼 폴더**. 만들 때마다 깨끗하게 새로 만들어서,
     내 `생성결과`·`검수결과` 같은 개인 파일이 들어가지 않습니다. (`rules` 폴더는 들어갑니다)
4. 공유용 폴더를 오른쪽 클릭 → **보내기 → 압축(ZIP) 폴더**(Windows 11은 **ZIP 파일로 압축**)로 압축해서 보내면 됩니다.
   받는 분용 `사용안내.txt`와 오픈소스 고지(`라이선스` 폴더)가 함께 들어 있습니다.
5. exe 폴더 안의 파일(`MELLOY 캐릭터 검수기.exe`, `_internal`, `rules`)은 항상 같은 폴더에 있어야 합니다.
   처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
6. `app.py`가 바뀌면 `exe만들기.bat`을 다시 실행해야 exe에 반영됩니다. (`rules` 폴더 내용은 exe를 다시 만들 필요 없이 바로 반영됩니다)

## 작성 탭 (템플릿 양식으로 변환 파일 만들기)
`rules/템플릿.md`의 `##` 제목 단위로 칸이 나뉩니다. 칸마다 자연어로 채우면 템플릿 양식 그대로 변환 파일을 만들어 줍니다. **AI 없이 동작합니다.**

1. **원자료 양식 만들기** — 제목에 `#`이 없는 자연어 양식(`원자료양식.txt`)을 만듭니다.
   AI 어시스턴트에게 이 양식을 주고 "이 제목 순서대로 원자료를 써 줘"라고 하면 됩니다.
   (`rules/템플릿.md`를 고쳤다면 이 버튼으로 양식을 다시 만들어 주세요.)
2. **불러오기** — 그렇게 쓴 원자료를 열면 제목(`등장인물`, `0. Core` 등)을 찾아 칸에 자동으로 채웁니다.
   저장해 둔 변환 파일(`# 제목` 있는 파일)도 열어서 이어 쓸 수 있습니다.
3. 왼쪽 목록에서 칸을 골라 고칩니다.
   - 변수·로어북은 입력 칸으로 나뉘어 있고, `[변수 이름]`, `N. 트리거:` 같은 형식은 저장할 때 자동으로 붙습니다.
   - 아래쪽에 글자 수(등장인물·설명)와 **설정 크기·예상 토큰**, **실시간 점검**(200자 초과, 변수·로어북의 `{{user}}`, 채우지 않은 안내 문구 등)이 표시됩니다.
4. **✨ 이 칸 AI로 다듬기** (선택) — 그 칸 하나만 Claude에게 보내 템플릿 형식에 맞게 다듬습니다.
   - 결과는 바로 바뀌지 않고, 현재 내용과 나란히 보여 준 뒤 **적용**을 눌러야 바뀝니다. (적용 후 Ctrl+Z로 되돌릴 수 있습니다)
   - 위쪽 요청 칸에 "말투 예시를 더 구체적으로"처럼 원하는 점을 적을 수 있습니다.
   - "문서 전체도 참고"를 켜면 다른 칸과 어긋나지 않게 확인하지만, 사용량이 크게 늘어납니다.
5. **저장** — `생성결과` 폴더에 변환 파일로 저장합니다. 원자료 파일은 덮어쓰지 않습니다.
6. **검수 탭으로 보내기** — 변환 결과(와 불러온 원자료)를 검수 탭으로 넘기고 기계 검사를 바로 실행합니다.

※ 작성 탭은 등장인물 한 명을 기준으로 합니다.

## 모바일 작성기 (`모바일/작성기.html`)
휴대폰 브라우저에서 쓰는 작성 탭입니다. AI 기능은 없고, 작성과 실시간 점검만 합니다. 점검 기준은 PC판 기계 검사와 같습니다.
- **원자료 붙여넣기 / 파일 불러오기**로 칸을 채우고, 칸마다 고칩니다. 쓰는 내용은 그 휴대폰의 브라우저에 자동 저장됩니다.
- 첫 화면에 **설정 크기**(세계관 / 주연 / 조연 / 로어북)와 예상 토큰이, 아래쪽에 글자 수가, 위쪽 **점검** 버튼에 고칠 곳 개수가 표시됩니다.
- **내보내기**: 변환 파일(.md)로 저장하거나 전체를 복사해서 Claude 앱 채팅에 붙여넣어 검수를 맡기면 됩니다.
- **HTML 미리보기** (목차의 미리보기 섹션 또는 메뉴): 상태창·소개문 HTML(`<html>`·`<body>` 없는 조각도 됨)을 붙여넣어 바로 봅니다.
  - 칸은 **멜로이 상태창 8,000자 / 멜로이 소개문 30,000자 / 루모 상태창 30,000자 / 루모 소개문 50,000자**로 따로 저장하고 따로 셉니다.
    글자 수는 다른 칸과 같은 UTF-16 기준이고, 권장선(최대 × `권장_비율`)을 넘으면 ▲, 최대를 넘으면 ✕입니다. 상태창(멜로이·루모)에 `{{user}}`가 있으면 ✕('유저'로 표기).
  - **플랫폼 규칙 검사**: 공개된 규정대로 막히는 것을 찾아 무엇을 왜 뺐는지 줄 번호와 함께 보여 주고, 미리보기에서도 빼고 보여 줍니다(끄기 가능).
    멜로이 상태창·루모 상태창은 허용 태그 밖의 태그, 멜로이 소개문은 script·iframe·embed·object, https가 아닌 이미지, Google Fonts가 아닌 외부 CSS,
    다른 호스트를 `@import`하는 `<style>`을 뺍니다. on… 속성과 `javascript:` 주소는 모든 검사 칸에서 뺍니다.
    (`<style>` 2개 이상, 앵커 이동, 루트가 `<div>` 하나가 아님은 ▲ 경고만). 실제 플랫폼 처리와 다를 수 있는 흉내입니다.
  - 폭(모바일 380 / 태블릿 768 / PC 전체 폭)과 배경(밝게 / 어둡게)을 바꿀 수 있습니다.
  - `{{user}}`, `{{char}}` 같은 `{{...}}` 변수를 찾아 목록으로 보여 주고, 임시 값을 넣으면 미리보기에만 반영합니다. (원본은 그대로, 치환 켜기/끄기 가능)
  - 미리보기는 `sandbox` iframe에서 열리고 스크립트는 기본으로 실행하지 않습니다. 칸별 규정과 허용 태그는 **규정 보기**에 있습니다.
  - 입력 내용과 변수 값은 그 기기 브라우저에 저장됩니다.
- **메뉴 › 원자료 양식 받기**: PC판과 같은 자연어 원자료 양식을 복사하거나 저장합니다.
- **메뉴 › 규칙 바꾸기**: `rules` 폴더의 `템플릿.md`, `검수설정.json`을 넣으면 그 휴대폰에서만 규칙이 바뀝니다.
  (페이지에 기본으로 들어 있는 규칙은 만들 당시의 `rules` 폴더 내용입니다.)
- **웹 주소로 배포**: `모바일/작성기.html`을 고친 뒤 `python 모바일/웹배포_만들기.py`로 `모바일/웹배포` 폴더를 다시 만들고
  `main`에 올리면 GitHub Actions가 자동으로 위 주소에 배포합니다. 안드로이드 크롬에서는 **앱 설치**가 됩니다.
  (`모바일/웹배포`는 직접 고치지 말고 항상 스크립트로 만듭니다.)

## 검수 탭 사용 순서
1. **원본 설정 불러오기** / **생성 결과 불러오기** 버튼으로 파일을 엽니다. (창에 파일을 끌어다 놓아도 됩니다)
2. **기계 검사 실행** — 즉시 검사합니다.
   - 등장인물 필드 5,000자 / 설명 필드 10,000자 초과 여부
   - `{{user}}` 금지 위치 (다른 변수 안 중첩, 섹션 제목, 금지 섹션) 및 표기 실수
   - 필수 섹션, 템플릿 헤더, 원본 헤더 누락
   - 설정 크기 (아래 참고)
3. **AI 의미 검수 실행** — `claude -p`를 백그라운드로 호출해 누락 / 규칙 약화(기계어치환 원칙 위반) / 환각을 찾습니다.
4. **결과 저장** — `검수결과` 폴더에 텍스트 파일로 저장됩니다.

결과 표시: ✔ 정상 · ▲ 경고 · ❌ 실패

## 파일 형식
섹션 제목은 한 줄에 단독으로 `# 제목` 형태로 적습니다. (`[변수 이름]`처럼 대괄호로 시작하는 줄은 제목이 아니라 본문으로 봅니다.) JSON 파일도 읽을 수 있습니다.
`예시` 폴더의 파일로 먼저 시험해 보세요.

## 1인 / 다인 모드
창 오른쪽 위 **규칙** 칸에서 모드를 고릅니다. (모바일 작성기는 첫 화면의 **모드 바꾸기**)
- **1인**: 캐릭터 한 명. `rules` 폴더의 규칙을 씁니다.
- **다인**: 다인챗. `rules/다인` 폴더의 규칙을 씁니다.
  - 작성 탭의 `등장인물`이 **인물별 카드**로 바뀝니다. 카드 추가·이름 바꾸기·순서 바꾸기·지우기가 되고,
    칸 구성(신상·코어·행동·관계·말투·고정 규칙)은 모든 카드에 똑같이 붙습니다.
  - 원자료 양식에서 카드는 `■ 캐릭터: 이름` 줄로 시작합니다. 인물마다 이 줄부터 '고정 규칙'까지 한 벌씩 씁니다.
  - **조연**: 주연 카드와 같은 칸으로 쓰고, 원자료에서는 `■ 조연: 이름` 줄로 시작합니다. 조연이 없으면 비워 두면 됩니다.
    조연은 로어북처럼 이름·키워드로 불려 나와 턴당 최대 2명까지 실리므로, 설정 크기에는 가장 긴 조연 2명만 더합니다.
  - 추가 점검: 설명 필드 목표 7,000자, 카드 인당 5,000자(목표 2,500자)·칸 누락, '캐스트 구성' 명단과 카드 이름 대조,
    변수 개수(텍스트 8 / 게이지 3), 로어북 구분선 12자·명령어 출력 형식, '한 턴에 ○분' 같은 턴 단위 시간 표현
  - AI 의미 검수의 '규칙 위반' 항목이 다인챗 규정의 원칙·최종 점검 항목까지 봅니다. (1인 모드는 작업지침의 판정 기준과 문체지침 기준)
- 템플릿의 `※` 메모 줄은 작성 안내로만 보여 주고, 변환 파일에는 넣지 않습니다.
- 마지막으로 쓴 모드를 기억합니다. 모바일 작성기는 모드마다 작업이 따로 저장됩니다.

## 설정 크기와 예상 토큰
MELLOY 화면처럼 **세계관(설명) / 주연 / 조연 / 로어북**으로 나눠 더합니다. (공백 포함 글자 수)
- 로어북은 한 번에 실리는 최대 3,000자까지만, 조연은 턴당 최대 2명(가장 긴 2명)까지만 더합니다.
- 예상 토큰은 글자당 0.65~1.05토큰으로 잡은 **추정치**입니다. MELLOY 표시와 조금 다를 수 있습니다.
- 권장 20,000자 / 최대 30,000자를 넘으면 경고합니다. 숫자는 `검수설정.json`의 `합계_제한`, `토큰_환산`, `표시_이름`에서 바꿉니다.

## 글자 수 세는 법과 경고 기준
- **UTF-16 기준**으로 셉니다. MELLOY·루모 화면(자바스크립트 문자열 길이)과 같은 방식이라, 이모지는 대부분 2자, 변이 선택자가 붙은 이모지(❤️ 등)는 3자로 셉니다. PC판과 모바일 작성기가 같은 숫자를 냅니다.
- 칸마다 **권장선과 최대선 두 단계**로 봅니다. 권장선을 넘으면 ▲ 주의, 최대선을 넘으면 ❌ 오류입니다.
- 권장선은 기본으로 **최대 × 2/3**입니다 (설정 크기 권장 20,000 / 최대 30,000과 같은 비율). 예: 등장인물 5,000자 → 권장 3,333자, 설명 10,000자 → 권장 6,667자.
- 비율은 `검수설정.json`의 `권장_비율`에서 바꿉니다. 칸에 `"권장"`이나 `"목표"`를 따로 적으면 그 값이 우선합니다 (다인 모드의 설명 목표 7,000자, 카드 목표 2,500자가 그 예입니다).
- 예전 설정 파일의 `경고_비율`은 더 이상 쓰지 않습니다. 지워도 되고, 남아 있어도 무시됩니다.

## 규칙 바꾸기 (`rules` 폴더, 메모장으로 수정)
| 위치 | 파일 | 역할 |
|---|---|---|
| `rules`, `rules/다인` | `검수설정.json` | 글자 수 한도, 설정 크기·토큰 환산, 필수 섹션, `{{user}}` 금지 섹션, 다인 추가 점검, AI 제한 시간 |
| | `템플릿.md` | 작성 탭 칸 구성 + 결과물에 꼭 있어야 하는 헤더 (`※` 줄은 작성 메모) |
