# charameka — 경량봇 작성기 · HTML 미리보기

브라우저에서 쓰는 웹앱 두 개입니다. 휴대폰·태블릿·PC 어디서나 열 수 있고, 각각 따로 앱으로 설치됩니다.

| 앱 | 주소 | 하는 일 |
|---|---|---|
| 경량봇 작성기 | https://m1nch0wh4ck.github.io/charameka/writer/ | 경량 코어 시트를 칸에 채워 점검하고, 멜로이 변환 파일과 크랙용 묶음을 만든다 |
| HTML 미리보기 | https://m1nch0wh4ck.github.io/charameka/html/ | 멜로이·루모 상태창·소개문 HTML을 붙여넣어 확인한다 |

예전 주소 `/charameka/`는 작성기로 넘겨 줍니다. 예전 주소로 앱을 설치했다면 지우고 새 주소에서 다시 설치해 주세요. 기기에 저장된 작업은 그대로 남습니다.

설치: 안드로이드 크롬은 메뉴(⋮) → **앱 설치**, 아이폰·아이패드 사파리는 공유 → **홈 화면에 추가**, PC 크롬·엣지는 주소창의 설치 아이콘. 한 번 열어 두면 인터넷이 없어도 열립니다. 작성 내용은 그 기기의 브라우저에만 저장되고 어디에도 전송되지 않습니다.

## 경량봇 작성기

경량봇(1인) 전용입니다. 규칙은 `rules/경량/`(템플릿.md·검수설정.json)이고, 숫자의 기준은 Bot-Workshop `3사_플랫폼_기능매핑_밀도지침.md`의 '경량 트랙' 절입니다. AI 기능은 없고 작성과 실시간 점검만 합니다.

- **원자료 양식 = 경량 코어 시트 양식.** 메뉴 › 원자료 양식 받기로 받은 자연어 양식(`#` 없음)을 채워 **원자료 붙여넣기**로 넣으면 칸이 채워집니다. 칸마다 고칠 수도 있습니다.
- 쓰는 동안 칸별 글자 수, 설명+등장인물 합계, 변수 개수·내용 200자, 로어북 항목 400자, `{{user}}` 위치를 점검합니다. 위쪽 **점검** 버튼에 고칠 곳 개수가 나옵니다.
- **내보내기**
  - 변환 파일(.md): `# 설명`·`# 등장인물`·`# 변수`·`# 로어북`을 멜로이 각 칸에 붙여넣습니다.
  - **크랙용 묶음**: 프롬프트(등장인물+설명) 한 덩어리, 키워드북 노트, 판매면 칸을 하나씩 복사합니다. 변수는 크랙에 없어 빠지고, 내용이 빈 소제목(세이프티판의 빈 '수위' 등)은 뺍니다.
- 메뉴 › 규칙 바꾸기: `rules/경량/`의 파일을 넣으면 그 기기에서만 규칙이 바뀝니다.

## HTML 미리보기

- 칸은 **멜로이 상태창 / 멜로이 소개문 / 루모 상태창 / 루모 소개문**으로 따로 저장하고 따로 셉니다. 권장선을 넘으면 ▲, 최대를 넘으면 ✕입니다. 상태창에 `{{user}}`가 있으면 ✕('유저'로 표기).
- **플랫폼 규칙 검사**: 공개된 규정대로 막히는 태그·속성을 찾아 줄 번호와 함께 보여 주고, 미리보기에서도 빼고 보여 줍니다(끄기 가능). 실제 플랫폼 처리와 다를 수 있는 흉내입니다.
- 폭(모바일 380 / 태블릿 768 / 전체)과 배경(밝게 / 어둡게)을 바꿔 볼 수 있습니다.
- `{{user}}`, `{{char}}` 같은 변수에 임시 값을 넣으면 미리보기에만 반영합니다(원본은 그대로).
- 미리보기는 `sandbox` iframe에서 열리고 스크립트는 기본으로 실행하지 않습니다.

## 글자 수 세는 법

- **UTF-16 기준**, 공백 포함입니다. 멜로이·루모 화면과 같은 방식이라 이모지는 대부분 2자, 변이 선택자가 붙은 이모지(❤️ 등)는 3자입니다.
- 권장선과 최대선 두 단계로 봅니다. 칸에 `"목표"`가 있으면 그 값이, 없으면 최대 × `권장_비율`이 권장선입니다.
- 계산과 플랫폼 화면값이 다르면 화면값이 맞습니다.

## 고치는 법 (관리자용)

- 소스는 `모바일/작성기.html` **한 파일**입니다. 두 앱은 같은 코드에 제목·아이콘·설치 정보만 다릅니다.
- `rules/경량/`이나 `모바일/작성기.html`을 고친 뒤 `python 모바일/웹배포_만들기.py`를 실행하면, 작성기.html에 규칙을 넣고 `모바일/웹배포/`(writer/·html/·루트 안내 페이지)를 다시 만듭니다. `모바일/웹배포`는 직접 고치지 않습니다.
- 내용이 바뀌면 스크립트의 `VERSION`을 올려 휴대폰의 옛 캐시를 비웁니다.
- `main`에 올리면 GitHub Actions(`.github/workflows/pages.yml`)가 자동으로 배포합니다.
- 두 앱은 서로 겹치지 않는 형제 주소(`writer/`, `html/`)여야 합니다. 한 앱의 범위 안에 다른 앱이 들어가면 안드로이드 크롬에서 따로 설치되지 않습니다.
