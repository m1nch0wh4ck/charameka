MELLOY 캐릭터 검수기 - 사용 안내

[실행하기]
1. 받은 압축 파일을 풀어 주세요. (압축 파일 안에서 바로 실행하면 안 됩니다)
2. 폴더 안의 "MELLOY 캐릭터 검수기.exe" 를 더블클릭합니다.
3. 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] -> [실행] 을 누르세요.
   직접 만든 프로그램이라 서명이 없어서 뜨는 안내입니다.
   백신이 막으면 이 폴더를 예외로 추가해 주세요.

[주의]
- 폴더 안의 파일은 그대로 두고, 폴더째로 옮겨서 쓰세요.
  exe 파일만 꺼내서 옮기면 실행되지 않습니다. (_internal, rules 폴더가 같은 폴더에 있어야 합니다)
- 바탕화면에서 실행하고 싶으면 exe 를 오른쪽 클릭 -> [바로 가기 만들기] 로 만든 바로 가기를 옮기세요.
- Windows 10 이상에서 동작합니다.

[무엇을 할 수 있나요]
- 작성 탭: 템플릿 칸에 자연어로 채우면 템플릿 양식의 변환 파일을 만들어 줍니다. (AI 없이 동작)
  [원자료 양식 만들기] 로 받은 양식에 맞춰 쓴 원자료는 [불러오기] 로 칸에 자동으로 채울 수 있습니다.
- 검수 탭: 원본 설정과 생성 결과를 비교해 글자 수, {{user}} 위치, 필수 섹션 등을 검사합니다.

[AI 기능을 쓰려면 (선택)]
"AI 의미 검수", "이 칸 AI로 다듬기" 는 Claude Code 가 설치되어 있어야 합니다.
- 본인의 유료 Claude 요금제(Pro 이상)가 필요하며, 사용량은 본인 계정에서 나갑니다.
- 설치: Windows PowerShell 을 열고 아래 한 줄을 붙여넣습니다.
    irm https://claude.ai/install.ps1 | iex
  설치 후 명령 프롬프트에서 claude 를 입력해 로그인하고, 이 프로그램을 다시 실행하세요.
- AI 기능 없이도 작성 탭과 기계 검사는 그대로 쓸 수 있습니다.

[규칙 바꾸기]
rules 폴더의 파일을 메모장으로 열어 고칠 수 있습니다.
- 검수설정.json : 글자 수 한도 등 검사 기준
- 템플릿.md     : 작성 탭의 칸 구성과 필수 제목
- 작업지침.md   : AI 에게 전달되는 지침
